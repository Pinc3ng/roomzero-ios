📖 Panduan lengkap langkah demi langkah
Gratis, tanpa App Store. ROOMZERO dipasang lewat SideStore dengan Apple ID-mu sendiri. Laptop hanya dibutuhkan sekali untuk memasang SideStore; setelah itu instal, update, dan perpanjang langsung dari iPhone.

Sudah punya SideStore?

Buka halaman ini di Safari di iPhone, lalu:
Tambahkan ROOMZERO ke SideStore Tambahkan ke AltStore Unduh file .ipa (manual)

Kalau tombol pertama tidak membuka SideStore: salin link source, buka SideStore → Sources → + → tempel link → lalu di Browse pilih ROOMZERO → Get.

Belum punya SideStore? (sekali saja, butuh laptop)

  1. Di laptop (Windows / Mac / Linux), buka panduan resmi docs.sidestore.io dan ikuti cara instal yang disarankan di sana (saat ini memakai aplikasi iloader).
  2. Colokkan iPhone ke laptop, login dengan Apple ID-mu sendiri di aplikasi pemasang, lalu pasang SideStore. Langkah ini juga membuat "pairing file" yang dibutuhkan SideStore.
  3. Di iPhone: Pengaturan → Umum → VPN & Manajemen Perangkat → ketuk Apple ID-mu → Percayai.
  4. iOS 16 ke atas: nyalakan Pengaturan → Privasi & Keamanan → Mode Pengembang, lalu restart iPhone.
  5. Pasang aplikasi VPN lokal yang diminta SideStore (gratis di App Store) — SideStore memakainya untuk memasang dan memperpanjang aplikasi tanpa laptop.
  6. Buka SideStore, login Apple ID, lalu kembali ke bagian "Sudah punya SideStore?" di atas.

Langkah pemasangan SideStore bisa berubah mengikuti iOS terbaru; kalau ada yang berbeda, ikuti docs.sidestore.io.

Penting diketahui

  1. 7 hari: aplikasi dari Apple ID gratis berlaku 7 hari (aturan Apple, tidak bisa dihilangkan). Pasang perpanjangan otomatis di bawah supaya tidak perlu diingat. Kalau sempat kedaluwarsa: buka SideStore (VPN-nya menyala) → My Apps → Refresh. Data game-mu tidak hilang.
  2. Batas 3 aplikasi: Apple ID gratis hanya bisa 3 aplikasi sideload aktif sekaligus (SideStore sendiri dihitung satu).
  3. Update: kalau ada versi baru, SideStore memberi tahu — tinggal ketuk Update.
  4. Co-op: semua pemain harus memakai versi yang sama (lihat versi di menu utama).
  5. "Tidak dapat memverifikasi aplikasi" → ulangi langkah Percayai di atas. "Batas aplikasi tercapai" → hapus satu aplikasi sideload lain.

Perpanjangan otomatis (sekali setup)

Biar ROOMZERO tidak pernah kedaluwarsa, iPhone memperpanjangnya sendiri setiap hari:
  1. Di SideStore: buka Settings → nyalakan Background Refresh (kalau ada di versimu).
  2. Di aplikasi Pintasan / Shortcuts (bawaan iPhone): tab Otomatisasi → + → Waktu → pilih jam (misalnya 21.00), Setiap Hari → pilih Jalankan Segera → Berikutnya.
  3. Ketuk Otomatisasi Kosong Baru → Tambah Tindakan → cari SideStore → pilih Refresh All Apps (Segarkan Semua App) → Selesai.
  4. Biarkan aplikasi VPN lokal SideStore terpasang dan izinkan tersambung saat diminta; perpanjangan butuh VPN itu dan internet.
  5. Cek sesekali: di SideStore → My Apps, sisa hari ROOMZERO harus kembali ke 7 setelah jam otomatisasi lewat.

Nama menu bisa sedikit berbeda tergantung versi iOS dan SideStore. Kalau tindakan "Refresh All Apps" tidak muncul di Shortcuts, buka SideStore sekali dulu, lalu cari lagi.
