# ROOMZERO untuk iPhone

Survival horror · 1–4 pemain · iPhone & iPad (iOS 14+).

**Halaman pemasangan:** https://pinc3ng.github.io/roomzero-ios/ — buka di **Safari** di iPhone.

ROOMZERO dipasang gratis lewat **SideStore** dengan Apple ID milik pemain sendiri:

1. **Sekali saja (butuh laptop):** pasang SideStore mengikuti panduan resmi di <https://docs.sidestore.io>.
2. **Setelah itu (tanpa laptop):** buka halaman di atas → *Tambahkan ROOMZERO ke SideStore* → *Get*.
3. **Tiap 7 hari:** buka SideStore → *My Apps* → *Refresh* (data game tidak hilang).

Source SideStore / AltStore (kalau ditambahkan manual):

```
https://pinc3ng.github.io/roomzero-ios/apps.json
```

File `.ipa` ada di [Releases](https://github.com/Pinc3ng/roomzero-ios/releases). File ini belum ditandatangani; SideStore / AltStore menandatanganinya dengan Apple ID-mu saat dipasang.

Kredit aset (suara, model, tekstur, font) ada di menu **Kredit** di dalam game.
